### 👋 About Me

I'm a self-taught backend developer based in Bangalore.  
No CS degree — just ~14 months of building, breaking, and rewriting systems until they felt solid.

I care a lot about the unglamorous but critical parts:  
**auth flows, caching strategies, background jobs, rate limiting, and making things correct under concurrency.**

Currently finishing B.Tech in Mechanical Engineering at UVCE while actively looking for backend / full-stack roles at product companies.

<br/>

### 🚀 Projects

#### 🟣 [SocialBuzz](https://github.com/AshishResolute/socialBuzz)
A production-style social media backend focused on reliability and performance.

- JWT + **refresh token rotation** with reuse detection & session revocation  
- Redis cache-aside brought feed latency from **170ms → 5ms**  
- BullMQ for fan-out notifications + cursor-based pagination  
- **81.57% test coverage** (49 tests with Jest + Supertest)  
- Fully migrated to TypeScript + Docker Compose + GitHub Actions CI

`TypeScript` `Node.js` `PostgreSQL` `Redis` `BullMQ` `Docker`

<br/>

#### 🏦 [BankAPI](https://github.com/AshishResolute/bankapi)
Banking-style REST API where correctness comes first.

- PostgreSQL **row-level locking** for safe concurrent transactions  
- Redis + Lua scripts for rate limiting (Upstash)  
- JWT refresh token rotation  
- 70%+ test coverage  
- Live Swagger docs

`Node.js` `PostgreSQL` `Redis` `JWT` `Swagger`

<br/>

#### 💼 [Job Application Tracker](https://github.com/AshishResolute/tracker)
My first full end-to-end project — React frontend + Node/TS backend.

- Prisma ORM + PostgreSQL  
- Deployed (frontend on Vercel, backend on Render)

`React` `TypeScript` `Express` `Prisma` `PostgreSQL`
