## 👋 About

I'm a self-taught backend developer — no CS degree, ~14 months of hands-on, self-directed development, started programming in Dec 2024. I like working on the parts of a system that actually get tested under pressure: **auth, caching, queues, rate limiting, and correctness under concurrency.**

B.Tech at UVCE Bangalore,job-hunting for backend/full-stack roles at product startups.

<br/>

## 🚀 Projects

### 🟣 [SocialBuzz](https://github.com/AshishResolute/socialBuzz)
Social media backend — auth, caching, background jobs, testing.

- 🔐 JWT auth with full **refresh token rotation** (reuse detection, session revocation)
- ⚡ Redis cache-aside cut feed latency **170ms → 5ms**
- 📬 BullMQ fan-out notifications, cursor pagination
- ✅ **81.57% test coverage** across 49 Jest/Supertest tests
- 🐳 Docker Compose + GitHub Actions CI/CD
- 100% migrated to TypeScript

`TypeScript` `Node.js` `PostgreSQL` `Redis` `BullMQ`

<br/>

### 🏦 [BankAPI](https://github.com/AshishResolute/bankapi)
Banking-style REST API — correctness over speed.

- 🔒 PostgreSQL **row-level locking** for transaction safety
- 🚦 Redis-backed rate limiting via Lua scripts (Upstash)
- 🔁 JWT refresh token rotation
- ✅ 70%+ Jest/Supertest coverage
- 📄 Live Swagger docs on Render

`Node.js` `PostgreSQL` `Redis` `JWT`

<br/>

### 💼 [Job Application Tracker](https://github.com/AshishResolute/tracker)
Full-stack tracker — first end-to-end project, built and deployed.

- ⚛️ React frontend (Vercel) + Node/TS/PostgreSQL backend (Render)
- 🗄️ Prisma ORM

`React` `Express` `TypeScript` `Prisma`
