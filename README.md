### A bit about me

I’m a self-taught backend developer  at UVCE. I fell into backend because I like systems that stay correct under load — auth that doesn’t leak, caches that actually hit, transactions that don’t race, and tests that catch real bugs.

Most of my projects are full REST APIs with:

- JWT + refresh token rotation  
- PostgreSQL (transactions, row-level locking, careful queries)  
- Redis (cache-aside, rate limiting, queues)  
- Docker + CI  
- Solid test coverage with Jest + Supertest  

I’m currently open to **Backend / Full-Stack roles** (Bengaluru or Remote).

## Featured Projects

### [SocialBuzz](https://github.com/AshishResolute/socialBuzz) — Social Media Backend
A complete social backend: follow graph, paginated feed, likes, comments, and email notifications.

**What I focused on**
- Feed latency dropped from ~170 ms → ~5 ms with Redis cache-aside  
- JWT access + refresh token rotation with reuse detection  
- BullMQ for async email jobs  
- 81%+ coverage across 49 tests  
- Docker Compose + GitHub Actions CI  

**Stack:** Node.js · TypeScript · Express · PostgreSQL · Redis · BullMQ · Docker

---

### [BankAPI](https://github.com/AshishResolute/bankapi) — Banking REST API
Production-style banking API with concurrent-safe money movement and atomic rate limiting.

**What I focused on**
- PostgreSQL row-level locking to prevent race conditions on balances  
- Redis + Lua scripts for atomic rate limiting (Upstash)  
- JWT refresh rotation + HTTP-only cookies  
- 70%+ test coverage  
- Live on Render with full Swagger docs  

**Live docs:** [bankapi-1-5iag.onrender.com/api-docs](https://bankapi-1-5iag.onrender.com/api-docs/)

**Stack:** Node.js · Express · PostgreSQL · Redis · Docker · Swagger

---

### [Finance API](https://github.com/AshishResolute/finance_backend) — Analytics & Ledger API
Role-based finance backend with transaction ledger and aggregate analytics.

**What I focused on**
- RBAC (viewer / analyst / admin)  
- Safe dynamic SQL with field whitelisting (no injection)  
- Aggregate queries (SUM, CASE, GROUP BY) for dashboards  
- Clear separation of controllers, middleware, and auth  

**Stack:** Node.js · Express · PostgreSQL · JWT · RBAC
